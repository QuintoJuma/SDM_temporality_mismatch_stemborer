🧩 About the Project

This repository contains a complete workflow for species distribution modeling (SDM) and hypothesis testing for Busseola fusca and Chilo partellus. It includes scripts for preparing occurrence and environmental data, generating SDMs. Validation of predictions is performed by extracting raster values at species occurrence points and calculating standard metrics such as True Positives, False Positives, False Negatives, True Negatives, Precision, Recall, F1-score, and Accuracy. The outputs include CSV summaries, raster layers, and visualizations, enabling reproducible analyses and transparent reporting of model performance.
